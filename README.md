# Soemon007.github.io

Live site: https://soemon007.github.io

This repo only contains the **built output** of the portfolio, so please don't edit these files by hand.
They are generated from the source in [`Soemon007/rehan-portfolio`](https://github.com/Soemon007/rehan-portfolio)
(`bun run build:static`, output in `dist/`), and anything edited here is overwritten on the next deploy.

To change the site, edit the source, build it, and publish the result here.
The old Jekyll blog (posts and layouts) is still in this repo's git history; the last commit that contains it is `18a75f6`.
